## Strix Models (Recommended)

Strix Models is a curated list of tested and verified models optimized for security testing.

<Note>
Strix Models is completely optional. You can use any LiteLLM-compatible provider with your own API keys.
</Note>

### Why Strix Models?

Not all models perform equally well as security agents. Penetration testing requires models that can:

- Follow complex multi-step attack chains
- Accurately interpret tool outputs and error messages
- Maintain context across long security assessments
- Generate valid payloads and exploit code

We tested a select group of models specifically for security testing workloads and worked with providers to ensure optimal configurations. The result is a curated list we feel confident recommending for penetration testing.

<Tip>
Strix Models gives you access to these vetted model/provider combinations through a single API.
</Tip>

### Quick Start

```bash
export STRIX_API_KEY='your-strix-api-key'
export STRIX_LLM='strix/claude-opus-4.5'
```

<ParamField path="STRIX_API_KEY" type="string" required>
  Your Strix API key. Get one at [strix.ai/settings](https://strix.ai/settings).
</ParamField>

<ParamField path="STRIX_LLM" type="string" required>
  Model to use. Prefix with `strix/` for hosted models.
</ParamField>

### API Endpoint

```
https://models.strix.ai/api/v1/chat/completions
```

For custom integrations, set `LLM_API_BASE` to `https://models.strix.ai/v1`.

## Bring Your Own Key

Use models directly from providers by setting `LLM_API_KEY` and omitting the `strix/` prefix:

```bash
export LLM_API_KEY='your-provider-api-key'
export STRIX_LLM='openai/gpt-5'
```

Supported provider prefixes: `openai/`, `anthropic/`, `google/`, `openrouter/`.

For local models (Ollama, LMStudio), also set `LLM_API_BASE`:

```bash
export STRIX_LLM='ollama/llama3'
export LLM_API_BASE='http://localhost:11434'
```
