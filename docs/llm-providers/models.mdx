## Strix Router (Recommended)

<Note>
Strix Router is currently in **beta**. You can also use any LiteLLM-compatible provider with your own API keys.
</Note>

Strix Router is a curated routing layer for tested and verified models optimized for security testing.

### Why Strix Router?

- **Highest rate limits** - No throttling during intensive security assessments
- **Zero data retention (ZDR)** - Your prompts and responses are never stored
- **Reliable** - Built-in failover and load balancing across providers
- **Tested & benchmarked** - Every model is validated for penetration testing workloads

Not all models perform equally well as security agents. Penetration testing requires models that can follow complex multi-step attack chains, accurately interpret tool outputs, maintain context across long assessments, and generate valid payloads.

<Tip>
Strix Router gives you access to vetted model/provider combinations through a single API.
</Tip>

### Quick Start

```bash
export LLM_API_KEY='your-strix-api-key'
export STRIX_LLM='strix/claude-opus-4.6'
```

<ParamField path="LLM_API_KEY" type="string" required>
  Your Strix API key. Get one at [models.strix.ai](https://models.strix.ai).
</ParamField>

<ParamField path="STRIX_LLM" type="string" required>
  Model to use. Prefix with `strix/` for hosted models.
</ParamField>
