# Strix Documentation

Documentation source files for Strix, powered by [Mintlify](https://mintlify.com).

## Local Preview

Node and the Mintlify CLI are provisioned by [mise](https://mise.jdx.dev/getting-started.html) (see `mise.toml`). The
first time you use mise in this repo, run `mise trust` before `mise install`.

```bash
mise install   # provisions Node + the Mintlify CLI
mise docs      # serves the docs site locally
```
